# 🎁 Teacher's Day 2026 — Digital Tribute

A small digital gift created to celebrate the teachers who inspire, guide, and shape our future. ❤️

This project is a cinematic, interactive **Teacher's Day 2026 tribute website** built using pure HTML, CSS, and JavaScript.

## ✨ Features

* 🎁 Interactive digital gift opening
* ✨ Cinematic particle effects
* 🎵 Background music with smooth fade-in
* ❤️ Emotional teacher appreciation message
* 📝 Three original Roman Urdu shayaris
* 🎬 Smooth page transitions and animations
* 📱 Responsive design for phones and desktops
* 🎉 Animated Teacher's Day finale
* 🌐 Ready for GitHub Pages deployment

## 🛠️ Built With

* **HTML5** — Website structure
* **CSS3** — Styling, animations & responsive design
* **JavaScript** — Interactions, transitions & particle effects
* **GitHub Pages** — Website hosting

## 🎬 Experience

The website is designed as a **digital gift**, not a traditional scrolling website.

The experience flows through:

**🎁 Open the Gift**
↓
**❤️ A Message for Every Teacher**
↓
**📝 Shayari 01 → Shayari 02 → Shayari 03**
↓
**🎉 Happy Teacher's Day**
↓
**❤️ Thank You for Everything**

## 🚀 Run Locally

1. Clone this repository:

```bash
git clone https://github.com/YOUR-USERNAME/Teachers-Day-2026.git
```

2. Open the project folder.

3. Make sure `music.mp3` is in the same folder as `index.html`.

4. Open `index.html` in your browser.

## 🌐 Deployment

This project can be hosted easily using **GitHub Pages**.

Go to:

**Repository → Settings → Pages → Deploy from a branch → main → /(root)**
